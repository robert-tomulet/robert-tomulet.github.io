# Deployment Instructions - Aces Robotics CMS

## Files created
- `app/` - Flask application
- `uploads/` - uploaded images
- `instance/aces.db` - SQLite database
- `aces-cms.service` - systemd service
- `nginx-aces-cms.conf` - nginx configuration
- `create_admin.py` - admin user creation script
- `backup.sh` - daily backup script

## Local development
```bash
cd "/home/robert/Downloads/site ultima versiune"
source venv/bin/activate
python run.py
```

## Production deployment on Ubuntu server

### 1. Copy files to server
```bash
scp -r "/local/path/site ultima versiune" user@server:/tmp/acesrobotics
ssh user@server
sudo mv /tmp/acesrobotics /var/www/acesrobotics.dev/html
sudo chown -R www-data:www-data /var/www/acesrobotics.dev/html
```

### 2. Create virtual environment on server
```bash
cd /var/www/acesrobotics.dev/html
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Set a strong secret key
```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```
Edit `aces-cms.service` and replace `REPLACE_WITH_STRONG_SECRET` with the generated key.

### 4. Create admin user
```bash
source venv/bin/activate
python create_admin.py
```
Save the generated password securely.

### 5. Configure systemd
```bash
sudo cp aces-cms.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable aces-cms
sudo systemctl start aces-cms
```

### 6. Configure nginx
```bash
sudo cp nginx-aces-cms.conf /etc/nginx/sites-available/acesrobotics
sudo ln -sf /etc/nginx/sites-available/acesrobotics /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 7. Backup (optional)
```bash
chmod +x backup.sh
sudo cp backup.sh /etc/cron.daily/acesrobotics-backup
```

## Admin access
- URL: `https://acesrobotics.dev/admin`
- Username: `admin`
- Password: generated by `create_admin.py`

## Creating writer accounts
1. Log in as admin.
2. Go to "Writeri".
3. Click "+ Writer nou" and fill in the form.
4. Share the generated credentials with the writer.

## Security notes
- Keep `SECRET_KEY` secret and never commit it.
- Change the admin password after first login.
- The site uses HTTPS via Cloudflare/nginx.
- Session cookies are HttpOnly, Secure, SameSite=Lax.
- Uploaded images are validated and stored with random filenames.
